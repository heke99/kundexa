# Kundexa project memory

Detta är projektets korta, beständiga arbetsminne. Läs i följande ordning:

1. `current-state.md`
2. `open-blockers.md`
3. `next-actions.md`
4. relevanta domänfiler
5. `verification-matrix.md`
6. `session-log.md`

Regler:

- Källkod, migrationer och verifiering har företräde framför äldre dokumentation.
- Märk osäkra uppgifter som `UNVERIFIED`; gissa aldrig tenant-, provider- eller produktionsstatus.
- Nya beslut loggas i `decisions.md`. Nya fel får ett ID i `known-failures.md`.
- Avsluta varje arbetspass med att uppdatera nuläge, verifiering och session-logg.
- Arkiverat material är historik, inte kanonisk instruktion.
