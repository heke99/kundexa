# Glossary

- **Tenant**: isolerad kundorganisation i SaaS-plattformen.
- **Plattformslista**: central supplylista med allokerings- och revisionsspår.
- **Customer list**: tenantens operativa bearbetnings-/ringlista.
- **List member**: koppling mellan kundkort och bearbetningslista med köstatus/utfall.
- **Claim**: tidsbegränsat atomiskt ägarskap av jobb eller listmedlem.
- **Directory**: central normaliserad företags-/personkatalog.
- **Source fact**: källspecifikt fältvärde med provenance och licensregler.
- **Segment**: sparad katalog-/CRM-fråga som kan materialiseras.
- **Snapshot**: fryst resultatuppsättning för ett segment.
- **NIX**: svensk spärrkontroll för direktmarknadsföring/telefonkontakt.
- **Outbox**: transaktionell köpost för senare providerarbete.
- **RLS**: PostgreSQL Row Level Security.
- **SECURITY DEFINER**: PostgreSQL-funktion som körs med funktionsägarens rättigheter.
- **DSAR**: begäran om registerutdrag/rättelse/radering enligt dataskyddsregler.
- **Lineage**: spår från källa/plattformslista till tenant/team/säljare.
